# Slate v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan. Steps use checkbox (`- [ ]`) syntax. Each implementing agent works in an isolated git worktree against the **shared contracts** below, then the orchestrator integrates.

**Goal:** Add live-synced undo/redo + clear, two-finger/trackpad pan-zoom with fullscreen and a collapsible menu, full text editing + dashed shapes + better select, and an S Pen long-press radial tool menu — to the Slate whiteboard.

**Architecture:** A single unified Pointer-Events input layer (built in package B) drives draw / pan-zoom / long-press; the Konva Stage carries the viewport transform and objects stay in world coordinates so cross-device sync is unaffected. Work is split into 4 packages built in two parallel waves (A∥B, then C∥D) against fixed interface contracts.

**Tech Stack:** Vite, React 18, TypeScript, Konva + react-konva, perfect-freehand, @supabase/supabase-js v2 (Realtime broadcast), Vitest, Playwright.

## SHARED CONTRACTS (frozen — all packages code against these)

These are the only interfaces that cross package boundaries. They are frozen so A/B/C/D can be built without re-reading each other's code. **Package B owns and creates the B-prefixed contracts; C/D consume them.**

### C1 — Viewport (B creates `src/board/useViewport.ts`)
```ts
export const MIN_SCALE = 0.1
export const MAX_SCALE = 8
export interface Viewport { scale: number; panX: number; panY: number }
export interface ViewportApi extends Viewport {
  zoomAt(screenX: number, screenY: number, factor: number): void // zoom keeping the screen point fixed
  panBy(dxScreen: number, dyScreen: number): void
  zoomIn(): void
  zoomOut(): void
  reset(): void                                                  // scale=1, panX=0, panY=0
}
export function useViewport(): ViewportApi
```

### C2 — Coordinate conversion (B creates `src/board/viewport-math.ts`)
```ts
import type { Viewport } from './useViewport'
// world → screen (for HTML/SVG overlays positioned over the canvas wrapper)
export function worldToScreen(wx: number, wy: number, vp: Viewport): { x: number; y: number }
//   => { x: vp.panX + vp.scale * wx, y: vp.panY + vp.scale * wy }
```
Screen→world is handled inside `Canvas` via `stage.getRelativePointerPosition()` (returns world coords once the Stage transform is applied). **All `onPointer*` callbacks below deliver WORLD coordinates.** Stored object coordinates are world coords — unchanged.

### C3 — Unified pointer input (B rewrites `src/board/Canvas.tsx` to expose this Props shape)
```ts
export type SlatePointerType = 'pen' | 'touch' | 'mouse'
export interface SlatePointerInfo {
  pointerId: number
  pointerType: SlatePointerType
  activePointers: number      // how many pointers are currently down (1 = draw, 2 = gesture)
}
export interface CanvasProps {
  objects: BoardObject[]
  showGrid: boolean
  // viewport (from useViewport) — Canvas applies these to the Stage and handles wheel + 2-finger gestures internally:
  viewport: ViewportApi
  // unified single-pointer events, in WORLD coords (fired only when activePointers === 1 and not a gesture):
  onPointerDown?(world: { x: number; y: number }, info: SlatePointerInfo): void
  onPointerMove?(world: { x: number; y: number }, info: SlatePointerInfo): void
  onPointerUp?(world: { x: number; y: number }, info: SlatePointerInfo): void
  onDrawCancel?(): void        // called when a 2nd pointer lands or a long-press claims the gesture
  // selection (existing, unchanged semantics):
  selectable?: boolean
  selectedId?: string | null
  onSelect?(id: string | null): void
  onTransform?(id: string, patch: Partial<StrokeData & SegData & RectData & TextData>): void
  // text editing (C): double-tap/click an existing text object:
  onEditText?(id: string): void
}
```
B owns the implementation; C and D only READ this contract. C adds `onEditText` wiring + dash/fontFamily render props on objects; D adds long-press detection that calls `onDrawCancel` + opens its menu. Neither changes the gesture/viewport internals.

### C4 — Object data additions (C edits `src/lib/types.ts`, additive/optional)

export interface RectData { x: number; y: number; w: number; h: number; color: string; size: number; dash?: DashStyle }
export interface TextData { x: number; y: number; text: string; color: string; fontSize: number; fontFamily?: FontFamilyKey }

```bash
npx tsc --noEmit -p tsconfig.app.json && npx vitest run && npx playwright test
```
All must be green before deploying (`git push origin main`, the Pages workflow runs tsc+vitest+build).
